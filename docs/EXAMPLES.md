# Example library

The examples are ordinary canonical documents generated from vfxforge/presets.py:

| File | Demonstrates |
| --- | --- |
| examples/arcane_impact.vfx.json | particle burst, flash, ground rune, light, event |
| examples/fire_impact.vfx.json | fire particles, scorch decal, warm light |
| examples/healing_aura.vfx.json | looping ring particles, aura decal, light |
| examples/ground_warning_circle.vfx.json | telegraph circle, dust, damage event |
| examples/lightning_beam.vfx.json | segmented noisy beam, light, cast event |
| examples/weapon_trail.vfx.json | ribbon trail and sparks |
| examples/portal.vfx.json | looping imported `forge_totem.obj` mesh effect, motes, light |
| examples/dust_burst.vfx.json | dust cloud particles and ground shadow |

Use vfxforge preset list --json to discover names and vfxforge preset create NAME --output PATH to make a fresh copy.
